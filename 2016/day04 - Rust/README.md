# Build / Run

## Build

From `rust/`

```
cargo build [--release]
```

## Run

From `rust/`
```
cargo run [--release] [path]
```

or build then

```
rust/target/[release]/day04 [path]
```

Where `[release]` is:
* debug - for normal builds
* release for `--release` builds
